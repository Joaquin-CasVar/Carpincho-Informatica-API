Carpincho Informática

Bienvenido a la API de Carpincho Informática, una tienda de hardware. Desde acá se administran los productos (procesadores, placas de video y más), los usuarios (clientes y vendedores) y las ventas con su detalle y stock.

Rutas

  • /admin Panel de administración de Django
  • /api API REST navegable: productos, usuarios y ventas
  • /docs Documentación de la API
